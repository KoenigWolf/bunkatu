# BUNKATU - テキスト分割ツール

テキストを指定した文字数で簡単に分割できる Web アプリケーション。

## 🌟 特徴

- 💨 高速な処理とレスポンシブな UI
- 🎨 美しいアニメーションとインタラクション
- 🌓 ダークモード対応
- ⌨️ キーボードフレンドリーな操作性
- 📱 モバイルファースト設計

## 🛠️ 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **スタイリング**: Tailwind CSS + Shadcn UI
- **アニメーション**: Framer Motion
- **型システム**: TypeScript
- **フォーマッター**: Biome

## 🚀 開始方法

```bash
# リポジトリのクローン
git clone https://github.com/yourusername/bunkatu.git

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

## 📦 機能

- テキストの分割

  - 指定文字数での自動分割
  - 分割結果のコピー機能
  - 分割プレビュー

- UI/UX
  - スムーズなアニメーション
  - レスポンシブデザイン
  - アクセシビリティ対応
  - ダークモード
