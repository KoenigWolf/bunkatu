# ✂️ BUNKATU - 高速で直感的なテキスト分割ツール

指定した文字数で簡単にテキストを分割できる Web アプリケーション。  
**パフォーマンス最適化**、**アクセシビリティ**、**モダンな UI/UX** を重視して開発。

---

## 🚀 特徴
- ⚡ **高速処理**：Web Worker による非同期分割  
- 🎨 **モダンな UI**：直感的なアニメーションとレスポンシブデザイン  
- 🌙 **ダークモード対応**：環境に応じた適切な配色  
- 🎯 **キーボード操作対応**：アクセシビリティを考慮した設計  
- 📱 **モバイルファースト**：スマートフォンでも快適に操作可能  

---

## 🛠️ 技術スタック
| 技術 | 使用理由 |
|------|---------|
| **Next.js 14 (App Router)** | 高速なレンダリングと最新のサーバーコンポーネント対応 |
| **TypeScript** | 型安全な開発を実現 |
| **Tailwind CSS + Shadcn UI** | 柔軟なカスタマイズと開発速度の向上 |
| **Framer Motion** | 滑らかな UI アニメーションを実現 |
| **Web Worker** | 非同期処理で UI の応答性を向上 |
| **Biome** | 静的解析とフォーマットを統一 |

## 💻 セットアップ
開発環境をセットアップする手順。

```sh
# リポジトリのクローン
git clone https://github.com/yourusername/bunkatu.git

# ディレクトリへ移動
cd bunkatu

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

**開発環境の推奨バージョン**
- **Node.js**: 18+
- **npm**: 9+

## 🏗️ アーキテクチャ
このプロジェクトは **クリーンなコンポーネント設計** と **パフォーマンス最適化** を重視。  
以下のディレクトリ構成に基づいて設計されています。

```
bunkatu
├── src
│   ├── app
│   │   ├── layout.tsx   # アプリ全体のレイアウト
│   │   ├── page.tsx     # メインページ
│   ├── components
│   │   ├── features     # コア機能コンポーネント
│   │   ├── sections     # UIセクション
│   │   ├── ui           # 汎用UIコンポーネント
│   ├── hooks            # カスタムフック
│   ├── lib              # ヘルパー関数・ユーティリティ
│   ├── types            # TypeScriptの型定義
│   ├── styles           # グローバルスタイル
│   ├── pages            # Next.js のページ
```

## 🔧 環境変数
APIキーや設定値を `.env.local` に定義。

```sh
NEXT_PUBLIC_API_URL=https://api.example.com
```

環境変数の設定後、サーバーを再起動してください。
